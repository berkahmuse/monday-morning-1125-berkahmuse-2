Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc)
bounty on [make.fun](https://make.fun): one joke about Monday morning,
at most 200 characters.

## The joke

> Monday morning: my alarm clock filed for overtime, my coffee filed a
> complaint, and my bed filed for custody of me.

(115 characters.)

## Run it

```sh
python3 main.py
```

`main.py` builds the joke from three "filings" — the alarm clock, the
coffee, and the bed each lodge a formal complaint — and prints it as
exactly one line. The output is deterministic: every run prints the
same line.
